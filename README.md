# Python-Wordle-MasterMind-Game
A game of wordle and mastermind implemented in python! No more boring waiting, fire up a terminal and play a fun very known game!

It has been coded and tested on Linux, but it is coded to work with Windows and MacOS as well, any compat issues, contact me!

## How to use
Open a terminal window and navigate to the folder where you cloned this repo.
Enter into the "Code" folder and launch the script with:
```
python WordleMindGame.py
```
Or for python3:
```
python3 WordleMindGame.py
```
## How to play
To navigate through the program, just type the number of the selection and press enter, for more info on how to play, select the "How to play" option in-game.



It should work fine!
